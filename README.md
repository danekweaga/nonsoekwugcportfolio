# Nonso UGC portfolio

Source for [Nonso's tech and AI UGC portfolio](https://nonsoekwugcportfolio.vercel.app/). This is a static site. Open `index.html` in a browser, or deploy this repository to Vercel with **Framework Preset: Other** and no build command.

## Make changes

- `index.html` contains the copy, sections, links, and video cards.
- `redesign.css` contains the current visual design. `styles.css` provides the base layout.
- `script.js` enables click-to-play on the brand video thumbnails.
- `media/` contains the portrait, brand images, poster frames, and six optimized videos.

The four editing samples are the November 21–24 videos Nonso supplied. The GTA 6 sample uses the revised cut. The Teamily and Atria brand videos, and all page images, are bundled in this repository. No performance metrics or testimonials have been added without evidence.

The [review preview](https://nonso-ugc-portfolio-review-2026.nonsoandsuhanachatgp.chatgpt.site/) is a separate copy. GitHub commits will update the Vercel site only if its project is connected to this repository and branch. Check Vercel's deployment status after pushing a change.
